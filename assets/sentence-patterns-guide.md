# 보고서 문장 공식 사용안내서

## 이 도구는 무엇인가

「보고서 문장 공식」은 한국 기업 의사결정 보고서에서 뽑은 문장 패턴 22개를 빈칸 채우기로 바로 써 보는 도구입니다. 하고 싶은 말을 고르고 빈칸만 채우면, 조사까지 맞춘 보고서 문장이 나옵니다.

- **왜 필요한가:** AI는 전 세계 글을 배워서 "~하기 때문에 ~할 필요가 있습니다" 같은 서술형·번역투 문장을 씁니다. 한국 기업 보고서는 "~을 위해 ~ 구축"처럼 짧은 명사형 문장을 씁니다. 이 차이를 공식으로 익힙니다.
- **무엇이 들어 있나:** 보고서 문장의 기본형인 킬러문장 `(대상)으로 (상황)에서 (목적)을 위해 (수단)을 통해 (행동)`의 조합 8개와 정의·비교·전환·인과 등 문장 관계 10가지의 공식 14개, 실제 보고서 예문 91개, 그리고 같은 자리에 쓰는 보고서 어휘 240묶음(2,452단어)입니다.
- **누구를 위한 도구인가:** 보고서를 처음 쓰는 직원, AI 초안을 보고서 문체로 다듬어야 하는 실무자, 문장이 늘 길어지는 분께 맞습니다.

예문은 국내 대기업 보고서에서 가져왔고, 회사를 알 수 있는 이름과 수치는 가렸습니다.

## 시작하기

파일 하나(`sentence-patterns.html`)를 더블클릭하면 바로 열립니다. 설치나 로그인은 필요 없습니다.

1. 강사에게 받은 `sentence-patterns.html` 파일을 내 PC에 저장합니다. 바탕화면이나 문서 폴더 어디든 괜찮습니다.
2. 파일을 더블클릭합니다. 인터넷 창(크롬, 엣지 등)으로 열립니다.
3. 다른 프로그램(메모장 등)으로 열리면 파일을 오른쪽 클릭 → **연결 프로그램** → **Chrome** 또는 **Microsoft Edge**를 고릅니다.

- **인터넷이 막혀 있어도 됩니다.** 필요한 내용이 모두 파일 안에 들어 있습니다.
- **입력한 내용은 밖으로 나가지 않습니다.** 모두 내 PC 안에서만 처리됩니다.
- 휴대폰에서도 파일을 열면 같은 화면으로 쓸 수 있습니다.

## 3단계 사용법

화면은 위에서 아래로 단계 세 개뿐입니다. 예를 들어 "수익성을 높이려고 부서 간 협업 방식을 다시 짜야 한다"는 말을 보고서 문장으로 바꿔 봅시다.

1. **어떤 말을 하고 싶나요?** 버튼 11개 가운데 하나를 누릅니다. 목적과 할 일을 말하는 문장이니 **킬러문장**(누가·무엇을 위해·어떻게 한다)을 고릅니다.
2. **공식을 고르세요.** 공식이 여러 개일 때만 이 단계가 나옵니다. **목적 + 대상 + 행동** `(목적)을(를) 위해 (대상)을(를) (행동)`을 고릅니다. 가장 많이 쓰는 조합입니다.
3. **빈칸을 채우세요.** 문장 모양 그대로 노란 빈칸에 바로 입력합니다.
    - 목적: `수익성 극대화` / 대상: `부서 간 협업 체계` / 행동: `재정립`
    - 완성 문장: **수익성 극대화를 위해 부서 간 협업 체계를 재정립**
    - **복사**를 누르고 보고서에 붙여 넣습니다. 다시 쓰려면 **지우기**를 누릅니다.

- **조사는 자동입니다.** 입력한 말의 받침에 맞춰 을/를, 은/는, 으로/로가 바뀝니다.
- **단어가 떠오르지 않으면** 빈칸 바로 아래 **‘이 칸에 쓸 말’**을 봅니다. 지금 입력하는 칸에 맞는 묶음과 단어가 나오고, 단어를 누르면 칸에 들어갑니다. 다른 단어를 누르면 방금 넣은 단어만 바뀝니다.
- 빈칸 아래에는 각 빈칸에 무엇을 쓰는지 설명과 한 줄 요령(💡)이 나옵니다.
- 막히면 **예문 보기**를 눌러 실제 보고서 문장을 참고합니다.

## 다른 말 찾기

화면 맨 아래 **🔁 다른 말 찾기**를 펼치면, 흔한 말을 같은 자리에 쓰는 보고서 말로 바꿔 볼 수 있습니다.

보고서 어휘는 공공기관·대기업 보고서에서 모은 240묶음(2,452단어)입니다. 묶음마다 이름, 한 줄 설명, 단어, 주의가 붙어 있고, 쓰임에 따라 9갈래로 나뉩니다.

| 갈래 | 이럴 때 찾습니다 | 예 |
| --- | --- | --- |
| 보고 단계 | 계획·진행·결과를 보고할 때 | 추진, 완수, 달성 |
| 긍정 | 좋아진 상태나 성과를 말할 때 | 제고, 향상, 발전 |
| 부정·문제 | 문제와 어려움을 짚을 때 | 우려, 미흡, 둔화 |
| 연결어·어미 | 문장이나 단락을 이을 때 | 이에, 한편, 아울러 |
| 꾸밈말 | 정도·속도를 더할 때 | 꾸준히, 신속, 폭넓게 |
| 구조·단계 | 목차·체계·단계를 짤 때 | 비전, 추진경과, 로드맵 |
| 한자·축약 | 한자나 ‘~화’, ‘~성’으로 줄일 때 | 無, 내실화, 활성화 |
| 주제어 | 기반·방향 같은 주제를 말할 때 | 기반, 청사진, 전환 |
| 분야 | HRD·스마트팩토리·설문 등 특정 분야 | 코칭, 채용, 교육과정 |

1. 찾을 말을 입력합니다. 예: `개선`, `늘리다`, `문제`, `그리고`
2. 그 말이 들어 있는 묶음과 같은 자리에 쓰는 단어들이 나옵니다. 입력한 말은 파란 테두리로 표시됩니다.
3. 마음에 드는 단어를 누르면 복사됩니다. 보고서나 빈칸에 붙여 넣으세요.

- HRD·스마트팩토리·설문 같은 분야 용어는 **분야 어휘 포함**을 켜면 함께 찾습니다.
- 한 묶음의 단어는 뜻이 같은 말이 아니라 **같은 자리에 쓰는 말**입니다. 바꿔 넣은 뒤 뜻(좋음·나쁨, 정도)이 그대로인지 꼭 확인하세요. 예: ‘위기’와 ‘기회’는 같은 묶음에 있지만 바꾸면 뜻이 뒤집힙니다.
- ‘3% 증가’를 ‘약진’처럼 센 말로 바꾸면 과장이 됩니다. 숫자가 있는 문장은 숫자를 살리세요.

## 11가지 문장 관계 한눈에 보기

1단계 버튼 11개가 각각 어떤 말에 쓰는지 정리했습니다. 어느 버튼을 눌러야 할지 모를 때 보세요.

| 관계 | 이럴 때 씁니다 | 문장 모양 | 예문 |
| --- | --- | --- | --- |
| 킬러문장 | 무엇을 위해 무엇을 어떻게 할지 (기본형) | 누가·무엇을 위해·어떻게 한다 | 직원들의 개선성과와 동기부여가 부합되도록 개선활동에 대한 보상 체계 재정립 |
| 정의 | 낯선 개념이나 현재 상태를 한 문장으로 규정할 때 | A란 ~이다 | Smart Workplace란, 글로벌하게 소통하고 집단의 지혜를 Speedy하게 발휘할 수 있는 장 |
| 열거 | 같은 무게의 항목을 나란히 쓸 때 | A는 ~, B는 ~ | 직무수행의 전문성과 미래지향적 역량을 갖춘 인재로 육성 |
| 추가 | 기대보다 더 넓은 효과·대상을 덧붙일 때 | A뿐 아니라 B도 | 개선/개발 뿐만 아니라 조율/조정으로 성과창출 가능 업무도 포함 |
| 분포 | 전체 가운데 부분의 크기·비율을 보여 줄 때 | 전체 중 A는 ~ | PJT 제안 OOO건 中 신규 선정 OOO건과 이월 OO건 등 총 OOO건 수행 예정 |
| 전환 | 방향·방식이 바뀔 때 | A에서 B로 바꾼다 | 공격적 수주전략에서 수익성 위주의 수주로 전환 |
| 비교 | 상반되는 두 상황을 맞세워 문제를 드러낼 때 | ~이나, ~ (상반) | 전반적으로 성장세가 기대되나, 경쟁 여건은 악화 예상 |

| 인과 | 원인과 결과를 한 문장으로 이을 때 | ~로 인해 ~ | 최근 경영여건 악화와 해외 투자사업 부진 등으로 인해 그룹 수익성 압박 가중 |
| 종합 | 세부 사항을 묶어 한 말로 정리할 때 | A, B 등 C | ㅇㅇ광산, ㅇㅇ사업 등 비핵심 사업 Smart Exit 추진 |
| 순서 | 절차·단계를 진행 순서대로 쓸 때 | A하고, B하여 C | 직원들이 제안한 Idea를 직원들이 참여하여 키우고, 참여자들이 평가하여 선정 |

## 잘 쓰는 요령 5가지

공식은 메시지를 담는 그릇입니다. 다음 다섯 가지만 지키면 공식으로 만든 문장이 자연스러워집니다.

1. **할 말을 먼저 정합니다.** "독자가 이 문장에서 무엇을 알아야 하나"를 한 줄로 적은 뒤 공식을 고릅니다. 공식부터 고르면 모양만 그럴듯한 빈 문장이 됩니다.
2. **빈칸은 명사와 숫자로 채웁니다.** `많이 줄어든 비용` 대신 `비용 15% 절감`처럼 씁니다. 빈칸을 명사로 끝내야 조사도 자연스럽게 붙습니다.
3. **문장 끝은 명사로 맺습니다.** `~합니다`, `~할 필요가 있습니다` 대신 `구축`, `강화`, `추진 필요`로 끝냅니다. 한 문서 안에서는 끝맺음 모양을 하나로 맞춥니다.
4. **같은 말을 반복하지 않습니다.** 줄마다 `~을 통해`, `~을 위해`가 나오면 다른 공식(예: 수단 + 대상 + 목적)을 골라 문장 모양을 바꿉니다.
5. **예문은 구조만 빌립니다.** 예문의 내용이나 숫자를 내 보고서에 그대로 쓰지 않습니다. 예문의 숫자는 O로 가려 두었습니다.

## 실습 문제

아래 문장을 도구로 보고서 문장으로 바꿔 보세요. 답안은 하나의 예일 뿐, 정답은 여러 개입니다.

1. **원문:** "고객 불만이 늘고 있는데, 그 이유는 배송이 자꾸 늦어지기 때문입니다."
    - 고를 버튼: **인과**
    - 답안 예시: 원인 `배송 지연 반복` / 결과 `고객 불만 증가` → **배송 지연 반복 등으로 인해 고객 불만 증가**
2. **원문:** "예전에는 부서마다 따로 구매했지만, 이제는 본사에서 한꺼번에 구매하는 방식으로 바꾸려고 합니다."
    - 고를 버튼: **전환** → 공식 `(이전)에서 (이후)(으)로 전환`
    - 답안 예시: 이전 `부서별 개별 구매` / 이후 `본사 통합 구매` → **부서별 개별 구매에서 본사 통합 구매로 전환**
3. **원문:** "신입사원들이 빨리 적응할 수 있도록, 선배 사원을 멘토로 붙여 주는 제도를 만들어야 합니다."
    - 고를 버튼: **킬러문장** → 공식 **목적 + 대상 + 행동**
    - 답안 예시: 목적 `신입사원 조기 적응` / 대상 `선배 멘토링 제도` / 행동 `도입` → **신입사원 조기 적응을 위해 선배 멘토링 제도를 도입**

4. **원문:** "이번 교육 덕분에 직원들 실력이 많이 좋아졌습니다."
    - 고를 버튼: **인과**. 결과 칸 아래 **‘이 칸에 쓸 말’**을 보거나, **🔁 다른 말 찾기**에 `좋아지다`를 넣어 봅니다.
    - 답안 예시: 원인 `직무 교육 확대` / 결과 `직원 역량 향상` → **직무 교육 확대 등으로 인해 직원 역량 향상**
    - ‘극대화’, ‘도약’도 같은 자리에 쓰지만 뜻이 셉니다. 근거가 없으면 쓰지 않습니다.

다 쓴 뒤에는 스스로 물어 보세요. 숫자로 바꿀 말은 없는가? (예: ‘배송 지연 반복’ → ‘배송 지연 월 OO건’)

## AI와 함께 쓰기

AI가 쓴 초안도 이 공식으로 다듬을 수 있습니다. 쓰는 AI에 따라 두 가지 방법이 있습니다.

- **Claude를 쓸 때:** 강사가 나눠 준 `koreport-skill.zip`을 claude.ai의 **Customize → Skills**에 올리면, Claude가 보고서를 쓰거나 고칠 때 이 공식과 보고서 어휘를 직접 씁니다(Pro 이상 요금제, 코드 실행 기능을 켜야 함). 그다음 "이 문장을 보고서 문장 패턴에 맞춰 고쳐 줘"처럼 요청하면 됩니다.
- **ChatGPT 등 다른 AI를 쓸 때:** 아래 프롬프트를 붙여 넣고 고칠 문장을 달아 주세요. 이 안내서의 ‘11가지 문장 관계’ 표와 ‘다른 말 찾기’의 9갈래 표를 함께 붙여 넣으면 더 정확합니다.

```text
아래 문장을 한국 기업 보고서 문체로 고쳐 줘.
- 먼저 이 문장이 어떤 관계(킬러문장, 정의, 열거, 추가, 분포, 전환, 비교, 개선, 인과, 종합, 순서)인지 골라 줘.
- 기본형은 "(대상)으로 (상황)에서 (목적)을 위해 (수단)을 통해 (행동)"이고, 필요한 요소만 골라 써.
- 문장 끝은 명사로 맺어(예: 구축, 강화, 추진 필요). "~합니다", "~할 필요가 있습니다"는 쓰지 마.
- 원문에 없는 숫자나 사실은 만들지 마.
- 흔한 말은 보고서 어휘로 바꾸되(예: 좋아지다 → 향상, 문제 → 애로), 뜻과 정도는 원문 그대로 둬.
- 고친 문장 1~2개와, 고른 관계 이름을 함께 보여 줘.

고칠 문장: (여기에 붙여 넣기)
```

AI가 고친 문장도 마지막에는 사람이 확인합니다. 특히 숫자와 사실이 원문과 같은지 봅니다.

| 영어 단어 뒤에 ‘은(는)’처럼 둘 다 나와요 | 영어는 받침을 알 수 없어서 둘 다 보여 줍니다. 복사한 뒤 맞는 쪽만 남기세요. |
| 복사 버튼이 안 눌려요 | 빈칸을 하나도 채우지 않으면 꺼져 있습니다. 채웠는데도 안 되면 완성 문장을 마우스로 끌어 선택한 뒤 Ctrl+C를 누르세요. |
| 화면을 닫으면 입력한 내용이 남아 있나요? | 남지 않습니다. 만든 문장은 복사해서 보고서나 메모에 바로 옮겨 두세요. |
| 휴대폰에서도 되나요? | 됩니다. 파일을 휴대폰에 저장해 열면 같은 화면이 작게 맞춰 나옵니다. |
| 추천 단어를 넣었더니 뜻이 이상해요 | 같은 자리에 쓰는 말이라 뜻과 정도가 조금씩 다릅니다. 묶음 아래 설명과 ‘주의’를 보고, 문장의 뜻에 맞는 단어로 고르세요. |
| 원하는 공식이 없어요 | 가장 가까운 공식으로 만든 뒤 직접 고치세요. 자주 필요한 문장 모양은 강사에게 알려 주세요. |
