## Ⅰ. 검토 배경
HL: 보고서 작성에 주당 6시간을 쓰는 반면 재작성 비율이 40%에 달해, **작성 방식 표준화**가 시급
❍ 시간 부담 : 팀원 1인당 보고서 작성에 주 6시간 투입(전체 업무시간의 15%)
• 임원 보고 1건당 평균 3회 수정, 재작성 비율 40%
• 수정 사유 1위 '결론 불명확'(52%), 2위 '근거 부족'(27%)
☞ 쓰는 시간보다 **고치는 시간**을 줄이는 방법이 필요
❍ 외부 변화 : 동종사 3개社 中 2개社가 보고서 AI 도구를 이미 시범 운영
• A社 : 초안 작성 시간 40% 단축('26.上 시범 결과)
☞ 도입이 늦어지면 보고 속도·품질 격차가 커질 우려
"그렇다면 우리 팀의 보고서는 어디서 시간이 새고 있는가?"

## Ⅱ. 현황 및 이슈
HL: 시간 손실은 쓰기보다 **기획·수정 단계**에 집중(전체 작성시간의 65%)
【작성 단계별 시간 비중】
| 단계 | 비중 | 주요 손실 요인 |
| --- | --- | --- |
| 기획(독자·메시지) | 25% | 방향 미확정 상태로 착수 |
| 작성(문안·장표) | 35% | 장표 디자인 반복 작업 |
| 수정(피드백 반영) | 40% | 결론·근거 재구성 |
❍ 이슈 : 메시지가 정해지기 전에 장표부터 그려 수정이 반복
• 장표 디자인에 쏟은 시간의 절반이 수정 단계에서 버려짐
* 출처 : 팀 내부 설문('26.10, n=24), 단위 : 작성시간 대비 비중

## Ⅲ. 추진 방향 @ppt-master
HL: **문안 먼저, 장표는 나중에** — 메시지를 확정한 뒤 장표는 자동으로 찍어 낸다
SUB: 기획은 사람이 판단하고, 문안은 AI가 돕고, 장표는 도구가 만든다
【As-Is】
❍ 장표를 그리며 생각을 정리
• 디자인 → 문안 → 메시지 순
• 수정 때마다 장표 재작업
||
【To-Be】
❍ 메시지를 확정한 뒤 장표화
• 메시지 → 문안 → 장표(자동) 순
• 수정은 문안 한 곳에서만
☞ 장표 재작업이 사라져 수정 시간 절반 단축 기대

## Ⅳ. 추진 내용
HL: 3단계로 도입하되, **1단계는 기존 PC·양식 그대로** 시작해 추가 비용 없음
❍ 1단계(~'26.12) : 문안 표준 양식과 AI 작성 가이드 배포
▷ 지표 : 재작성 비율 40% → 25%
❍ 2단계(~'27.3) : 자동 장표 생성 도구 시범 적용(2개 팀)
▷ 지표 : 장표 작성시간 50% 단축
❍ 3단계(~'27.6) : 전사 확산과 우수 사례 공유
※ 2단계 결과를 보고 3단계 범위를 조정

## Ⅴ. 종합
