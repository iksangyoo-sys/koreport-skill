# report_spec.md 문법

문안을 장표로 그대로 옮길 수 있게 만든 Markdown 형식이다. 한국 기업 1-page 장표의 기호를 그대로 쓰므로 사람이 읽어도 장표처럼 읽힌다. 빈 양식은 `templates/report_spec_template.md`(여러 장·세로), `templates/onepage_spec_template.md`(가로 견본 배치).

## 머리말 (표지)

```markdown
---
title: 보고서 제목              # 표지 제목
subtitle: 부제                  # 선택
date: '26. 11. 9               # 표지 좌상단
dept: 작성 부서                 # 표지 우하단
raci: R 작성 / A 승인 / I 보고  # 선택
toc: 장1 | 장2 | 장3            # 표지 목차 키워드 4~5개
cover: yes                      # no 면 표지 생략
---
```

## 장표

| 줄 형식 | 의미 | 렌더링 |
|---|---|---|
| `## Ⅰ. 검토 배경 _ 소제목` | 새 장표 | 상단 블루 바, 우상단 '현재/전체' 쪽 번호 |
| `## … @ppt-master` | PPT Master로 다시 그릴 장 | 기본 덱에는 문안대로 그리고 "PPT Master 대상" 표시 |
| `## [간지] Ⅱ. …` | 간지 | 가운데 블루 띠 |
| `## [첨부1] …`, `## [참고] …` | 보조 장 | 진한 바, 쪽 번호 없음 |
| `HL: …` | 헤드라인(결론 1~2줄) | 블루 굵게 17pt + 아래 선 |
| `SUB: …` | 서브라인 | 진한 남색 13.5pt |
| `【블록 제목】` | 표·박스 제목 | 옅은 블루 바탕 라벨 |
| `❍ ■ ○ □` | 1단계 묶음 문장 | 14pt 굵게 |
| `•` | 2단계 근거 | 13pt, 들여쓰기 |
| `-` | 3단계 하위 근거 | 12pt, 더 들여쓰기 |
| `☞` | 시사점 | 진한 남색 굵게 |
| `※` | 보충·전제 | 회색 11pt |
| `▷` | 부연·지표 띠 | 12.5pt, 들여쓰기 |
| `**핵심어**` | 강조 | 블루 굵게 (헤드라인 안에서는 남색) |
| `\| a \| b \|` | 표(첫 행 = 헤더) | 블루 헤더, 0.25pt 회색 가로선만, 숫자 가운데 정렬 |
| `\|\|` (한 줄 단독) | 여기서부터 오른쪽 단 | 좌우 2단 + 가운데 구분선 (As-Is/To-Be 등) |
| `* 각주`, `** …`, `1) …` | 장 하단 각주 | 회색 9.5pt |
| `"문장"` 또는 `“문장”` | 하단 따옴표 문장 | 하단 선 아래 가운데 |
| `NOTE: …` | 발표 메모 | 슬라이드 노트 |
| `<!-- … -->` | 주석 | 무시 |

## 쓰는 요령

- 장표 하나 = `##` 하나. 1 주제 1 장표.
- 표는 장당 1~2개, 항목 3~4개. 숫자 열은 단위를 표 제목(【 】)이나 각주로 올린다.
- 좌우 비교가 아니면 `||`를 쓰지 않는다(onepage-format §8 배치 규칙).
- 렌더러는 도형·도표를 그리지 않는다. 프로세스·개념도·차트가 메시지를 결정하는 장은 `@ppt-master`로 표시하거나, 표로 대신할 수 있는지 먼저 본다.
- 텍스트가 넘치면 렌더러가 자르지 않으므로 `--check`의 줄 수 경고를 따른다.

## 가로 견본 배치 문법 (`spec_to_onepage.py`, row.pptx)

row.pptx 본문 견본처럼 한 장을 ❍ 묶음 2~4개로 꽉 채우는 문안이다. `##` 장 제목 대신 머리말 `title`이 장 제목 바에 들어간다.

| 줄 형식 | 렌더링 |
|---|---|
| 머리말 `title:` / `pages:` / `page_titles: 1쪽 \| 2쪽` | 제목 바 문구 / 장 수 / 쪽별 제목 |
| `❍ 묶음 문장` (■ ○ □ 도 같음) | 15pt 굵게, `**핵심어**` 파란(#3333CC) 굵게, `__굵게__` 검정 굵게 |
| 묶음 바로 아래 `* …`, `※ …` | 회색 10.5pt 각주 |
| `【라벨 제목】` | 회색선 박스 안 회색 점무늬 라벨 바(남색 굵게) |
| `\| 표 \|` | 회색 헤더·가로선 표, 셀 안 `**값**`은 파란 굵게 |
| `\|\|` (또는 `\|\|60`) | 박스 오른쪽 단 시작, 가운데 점선 (왼쪽 비율 %) |
| `((포항/집중))`, `((인터뷰/결과\|gray))` | 원형 라벨('/' 줄바꿈), 색: mint(기본)·gray·blue·yellow |
| `•` / `-` / `▷` | 박스 안 근거 / 하위 / 부연 |
| `☞ …` | 박스 아래 13.5pt 굵은 시사점 |
| `"문장"` | 장 맨 아래 17pt 남색 따옴표 문장(장마다 1개) |
| `[새쪽] 제목` | 다음 장 시작 |

- 박스는 묶음 안에 표·라벨·원형 라벨·`||`가 있을 때 그려진다. 근거 문장만 있으면 박스 없이 들여 쓴다.
- 스크립트가 글자 배율(0.82~1.15)과 간격을 조절해 장을 꽉 채운다. 0.82로도 넘치면 경고를 내고, `--pages`를 주지 않았으면 다음 장으로 넘긴다.
