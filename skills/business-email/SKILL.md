# 업무 이메일 작성 스킬

업무 이메일을 쓰거나 교정할 때 쓰는 스킬이다. 교안 「업무 이메일 작성 Tip」의 작성 원칙, 요청 메일 Case Study 3건(원문 → 수정의견 → 수정 후), 업무보고 메일 예시 5건(설문결과·시작·중간·결과·재보고), 외부 벤치마킹 문의 메일, 아이스브레이킹 문구 모음을 정리했다.

보고서 일반 방법론(독자 니즈, 메시지 도출, 묶고–풀기, 문장 교정, 1-page 양식 등)은 `koreport-skill`을 따른다. 이 스킬은 그 위에 **이메일에 특화된 것**만 얹는다.

**핵심 한 줄: 업무 이메일은 받는 사람이 할 일부터 보이게 쓴다. 제목에 말머리·키워드·기한, 본문은 YOU 관점의 단문으로.**

---

## 0. 작업 순서

1. **유형 정하기**: 요청 / 공지 / 업무보고(시작·중간·결과·실적·재보고) / 협의 / 외부 문의 중 무엇인지 정한다. 유형에 따라 본내용 구성과 아이스브레이킹 사용 여부가 달라진다.
2. **수신자 확인**: 누구에게(직급, 친밀도, 사내·사외, 단수·다수) 보내는지 확인한다. 모르면 가정을 밝히고 진행한다.
3. **제목 작성 (2장)**: [말머리] + 키워드 + (기한).
4. **본문 구성 (1장 뼈대)**: 시작 인사 → (시작 I·B) → 용건요약 → 본내용 → (마무리 I·B) → 마무리 인사.
5. **유형별 본내용 작성 (3·4장)**.
6. **교정 (5장 체크리스트)**: 특히 I 관점 워딩, 중복어, 부탁·강조 부사 남발, 날짜 표기를 고친다.

## 1. 이메일 뼈대

| 구성 | 쓰는 내용 | 작성 요령 |
|---|---|---|
| **제목** | 말머리 + 키워드 + 기한 | 2장 참조 |
| **시작 인사** | 안녕하세요 + 수신자 이름·직책 + 발송자 소속·이름 | 수신자가 상위직급이면 발송자 직책명도 쓴다. 업무보고나 수시 소통에서는 '안녕하세요'를 생략해도 된다(예: "원장님, / 디지털혁신교육그룹 박ㅇㅇ입니다.") |
| **시작 I·B** | 날씨·계절·휴일 인사 | 바로 본론이 너무 사무적일 때만. **업무보고에는 쓰지 않는다** |
| **용건요약** | 메일의 목적, 본내용의 키워드 | 제목을 한 단계 구체화한 1~2줄. 본내용과 중복하지 않는다. 예) "지시하신 ㅇㅇ기술연구 결과입니다. 검토말씀 보완하여, 다음 주 화요일 대면 보고하겠습니다." |
| **본내용** | 요청·공지: 상대가 할 일, 회신기한, 공지사항, 문의처 업무보고·협의: 목적·취지·배경·경과, 이슈, 의견·개선방안 | 요청·공지는 개조식 또는 서술식, 보고·협의는 스토리 흐름에 따라 서술식 |
| **마무리 I·B** | 날씨·안부 인사 | 본내용 다음 바로 끝내기 어색할 때만. **시작 I·B와 겹치지 않게**. 업무보고에는 쓰지 않는다 |
| **마무리 인사** | 감사합니다 + 발송자 이름 + 드림(올림) | 상위직급·연장자에게는 '고맙습니다' |

## 2. 제목

- **말머리로 목적을 밝힌다**: [보고] [요청] [공지] [협의], 보고는 [시작보고] [중간보고] [결과보고] [보완보고] [설문결과]처럼 세분해도 된다.
- **키워드를 제목에 담는다**: "과제발굴 워크숍에 관한 내용의 건"(×) → "[공지] 9월 8일 과제발굴 워크숍 장소 변경"(○)
- **'안내'와 '요청'을 가른다**: 상대가 무언가를 해야 하면 안내가 아니라 요청이다. "~강의실적 취합 안내"(×) → "(요청) '22년 12월 원내강사 강의실적 취합"(○)
- **요청 메일은 수신자와 회신기한을 표기한다**(회신율이 30% 오른다). 예) (ㅇㅇㅇ님께) ~~~ (9.8까지)
- **기한은 시각까지, 괄호 안에 괄호를 넣지 않는다**: "(12/15(목)까지)"(×) → "(12.15 목 17:00까지)"(○). 날짜 형식은 본문과 같게 한다.
- **Re:/Fw:가 쌓이면 제목을 다시 쓴다**: "Re:Re:Re:Re: Fw: 율촌 산단 견학요청"(×) → "(요청) 율촌 산단 방문처 명칭 변경"(○)

## 3. 요청·공지 메일

### 3-1. 원칙: I 관점 안내문 → YOU 관점 요청문
- **수신자가 무엇을, 어떻게, 언제까지** 회신할지가 첫 화면에 보여야 한다.
- **결재용 배경 문장은 뺀다.** "만족도를 높이고자", "예산확보를 위해"처럼 경영층·직책자의 의사결정을 받을 때 필요한 기획 단계 문장은 수신자가 할 일을 흐린다.
- **회신할 내용을 본문 중심에 둔다.** 정작 수신자가 피드백해야 할 내용을 ※(당구장)로 처리하면 주객이 전도된다.
- **같은 주제끼리 번호로 묶는다.** "검진기관 → 독감접종 → (※) 검진기관 → 독감접종"처럼 왔다 갔다 하지 않게 "① 검진기관 ② 독감접종"으로.
- **할 일은 행동으로 쓴다.** 예) 희망 검진기관에 → 'O' 표기, 업데이트 완료 시 → 박스를 오렌지색, '완료'로 변경
- **수신자의 말로 쓴다.** "교재연구비 산정기간"은 급여담당(발송자)의 일이다. 수신자인 교육담당 입장에서는 "강의실적 취합 대상 기간"이다. "퇴근 전까지"도 I 관점이다 → "17:00까지".
- **부정문은 긍정문으로.** "기간 내에 보내지 않으면 급여에 반영되지 않음" → "12.15까지 품의한 실적만 12월 급여에 반영"

### 3-2. 본내용 덩어리 짓기
- 요청 메일은 **When(기한) → What(대상·조사내용) → Who/How(누가 어떻게)** 순으로 재구성한다.
- '주의사항' 덩어리를 따로 두면 앞의 내용을 다시 말하게 되어 흐름이 엉킨다. 주의사항은 해당하는 What·Who/How 아래로 나눠 넣는다.
- 레벨이 다른 내용은 불릿을 다르게 한다(○ → - → *).
- 개조식(~전달), 서술식(~부탁드립니다), 음슴체(~기재바람)를 섞지 않는다. 한 패턴으로 통일한다.
- 같은 대상을 다른 말로 부르지 않는다. 처음에 "원내강사(院소속 직원, 직책자)"로 정의한 뒤에는 "원내강사"로만 쓴다.
- 같은 기간을 두 번 쓸 때는 앞에는 "'22년 12월", 본문에는 "'22.11.16~12.15"처럼 나눠 단조롭지 않게 한다.

### 3-3. 요청 메일 양식

```
제목 : (요청) [키워드] (~MM.DD 요일 HH:00까지)

안녕하세요.
[소속] [이름]입니다.

[용건요약 1~2줄: 무엇에 필요한 자료를, 누가, 어떻게 회신해 달라는지]

○ 기한 : 'YY.M.D(요일) HH:00까지 [회신·배포 방법, 수신처]
    - [기한 관련 유의사항 1줄]
○ 대상(What) : [기간·범위]
    - [포함·제외 기준]
○ 방법(Who/How) : [누가] [첨부 양식에] [무엇을] 기재
    - [정확히 써야 할 항목과 그 이유]

[문의처: 이름(연락처)]

감사합니다.
[이름] 드림
```

## 4. 업무보고 메일

### 4-1. 원칙
- 호칭으로 바로 시작한다("원장님," → "디지털혁신교육그룹 박ㅇㅇ입니다."). **아이스브레이킹은 쓰지 않는다.**
- 첫 문장에 **무엇을(『과제명』) 어느 단계에서 보고하는지**와 **첨부·대면보고 여부**를 밝힌다.
- 본문은 개조식이 아니라 **서술식 스토리**로, 첨부 보고서의 요지를 메일만 읽어도 알 수 있게 쓴다.
- 끝에는 **대면·영상 보고 일정이나 제안**을 붙인다("자세한 내용은 오늘 오전 10시 30분 대면보고 드리겠습니다", "필요하시면 영상으로 보고드리겠습니다").

### 4-2. 유형별 흐름

| 유형 | 제목 예 | 본문 흐름 |
|---|---|---|
| **설문·진단 결과** | [설문결과] 디지털리터러시 진단결과 및 개선방안 보고 | 인사 → 용건요약(목적·방법) → 진단결과(현 수준 1줄 + 단계 정의 ※) → 향상방안(①~④, 각 시점) → 기대효과 → 대면 일정 → 인사 |
| **시작보고** | [시작보고] 그룹사 맞춤형 리/업스킬링 추진방안 | 인사 → 용건요약(사전 보고, 대면 일정) → 추진계획(분류·방법 → 첫 적용 대상과 절차 → 마감 시점과 그 이유 → 확산 계획) → 대면 안내 → 인사 |
| **중간보고** | [중간보고] ○○ 교과목 체계 구축 | 인사 → 용건요약(과제명·기간, 이번 보고 단계) → 추진실적(무엇을 몇 개로 정리했는지 수치) → 현재 진행 → 향후계획(언제까지 무엇, 종합보고 시점) → 설명 방식 제안 → 인사 |
| **결과보고** | [결과보고] ○○ 교육체계 구축 결과 | 인사 → 용건요약(기간·과제명) → 결과(핵심 산출물 수치) → 과정(이슈와 해결 방법) → 이해관계자 공유·후속 논의 → 향후 역할 분담 → 설명 방식 제안 → 인사 |
| **지시사항 실적·계획** | [보고] 기술계 사외 우수콘텐츠 보완방안 | 인사 → 용건요약(언제 지시하신 무엇, 결론) → 현황(비교 수치: 사무계 80% vs 기술계 20%) → 실적(무엇을 몇 개 확보) → 향후계획(누구와 협업해 무엇을) → 대면 일정 → 인사 |
| **재보고·보완보고** | [보완보고] '23년 실행운영계획 보완 | 인사 → 용건요약(무엇을 첨부로 보고) → 보완내용(언제 말씀하신 무엇을 반영, 그 밖에 바꾼 것, 추가한 것) → 의견 요청 → 다음 보고 일정 → 인사 |

- 재보고는 **"○월 ○일 말씀주신 ~을 추가했습니다"**처럼 지시와 반영을 짝지어 쓴다.
- 결과·중간보고는 산출물을 **수치**로 쓴다(24개 공정 표준화, 55개 하위 프로세스, 교과목 192개).

## 5. 외부 문의 메일 (벤치마킹·협조 요청)

처음 연락하는 외부인에게 무엇인가를 부탁할 때의 흐름:

**인사 → 소개(우리 기관, 나의 역할) → 용건(무엇을 왜 원하는지, 상대를 고른 이유) → 윈윈 포인트(상대가 얻을 것) → 회신 요청 → 마무리 인사**

- 상대를 고른 이유를 구체적으로 쓴다. 예) "'09년부터 배터리아카데미를 운영해왔고, 전문화된 교육체계(LBA, IBT 등)를 선도적으로 구축한"
- 부담을 줄이는 조건을 단다. 예) "보안이슈가 없는 범위 내에서"
- 회신받을 내용(방문 가능 여부)을 명시한다.

## 6. 이메일 표현 Q&A

| 질문 | 답 |
|---|---|
| 아이스브레이킹은 언제? | 처음 보내거나 오랜만에 보낼 때, 무언가를 간곡히 요청·당부할 때. **업무보고에는 쓰지 않는다** |
| 쿠션 워딩(~것 같습니다, ~라고 생각합니다, ~로 판단됩니다)? | 보고서에서는 책임회피·자신감 부족으로 보여 지양한다. 이메일에서는 적절히 쓰면 부드러워지므로 전체 맥락을 보고 쓴다 |
| 작일·금일·명일·차주 vs 어제·오늘·내일·다음 주? | 한글 표현이 추세. 고객이 원하면 한자어 |
| 이모티콘(^^, :))? | 문법대로 쓰면 오히려 어색하거나 친분이 있을 때. 예) "잘 지내셨나요?"(어색) vs "잘 지내셨나요^^". 다수 임직원 대상 격식 메일, 친밀도 낮은 상사·동료에게는 자제 |
| 감사합니다 vs 고맙습니다? | '감사합니다'가 무난. 상사나 나이 차이가 많은 사람에게는 '고맙습니다' |
| 안녕하십니까? | 업무 메일에서는 묻는 느낌이 어색할 수 있다. '안녕하세요.'가 자연스럽다 |

## 7. 교정 체크리스트

이메일 교정 시 아래 유형을 찾는다(Case Study 수정의견에서 뽑음).

1. **I 관점인가?** 발송자 사정(예산확보, 만족도 제고, 퇴근 전, 교재연구비 산정)이 앞에 있고 수신자가 할 일이 뒤에 묻혀 있지 않은가.
2. **할 일·기한·방법이 첫 화면에 보이는가?** 볼드·번호로 드러냈는가.
3. **주제가 왔다 갔다 하지 않는가?** 같은 주제끼리 묶었는가.
4. **용건요약이 본문과 중복되지 않는가?**
5. **사족이 없는가?** "~취합할 예정이오니, ~전달 부탁드립니다"는 '짜장면을 먹을 예정이오니 짜장면 주세요'와 같다. 결과 문장만 남긴다.
6. **중문을 단문으로 나눴는가?** 주술관계가 3개 들어간 문장은 나눈다.
7. **겹친 말을 지웠는가?** 조사를 진행 → 조사, 기간 동안 → 기간, 담당자분들께서는 → 담당자께서는, 배포로 전달 → 배포. "하기와 같이, 관련하여, 할 예정이오니"는 지워도 소통에 지장이 없다.
8. **부탁·격식어를 남발하지 않았는가?** '부탁드립니다' 6번 → 꼭 필요한 곳 1번. '많은, 바쁘시겠지만, 협조'도 줄인다.
9. **강조 부사를 남발하지 않았는가?** '꼭, 필히, 반드시, 명확히'는 정말 중요한 곳에 1번만.
10. **표기가 통일됐는가?** 날짜 형식(12.15 vs 12/15), 문장 패턴(개조식·서술식·음슴체), 대상 용어.
11. **긴 설명을 짧게 바꿨는가?** "기재해주시는 주소로 ~약이 발송되므로 꼭 현재 거주 중인 주소로" → "~약을 받을 실거주 주소 기재"
12. **I·B 규칙을 지켰는가?** 업무보고에 쓰지 않았는가, 시작과 마무리가 겹치지 않는가.

## 8. Case Study 요약 (원문 → 수정 후)

- 원문: 제목 "건강검진 및 독감예방접종 안내", 검진기관 이원화 취지·예산확보 배경이 본문 앞, 실제 회신 내용은 ※ 아래, '협조 부탁드립니다' 반복, 회신기한 "12월 18일 퇴근 전"

## 9. 아이스브레이킹 문구 (필요할 때만)

수신자·시기에 맞춰 1~2문장만 고른다. 시작과 마무리에 같은 소재를 쓰지 않는다.

- **연초**: "새해 원하시는 모든 일에서 큰 성취 이루시고, 복 많이 받으세요." / "올 한 해 물심양면으로 도와주신 ○○님께 감사드리며, 새해에도 큰 성취 이루시면 좋겠습니다."
- **연중**: "즐겁고, 행복하고, 건강한 ○월 보내시길 기원합니다." / "안전하고 건강한 한 주 보내시기 바랍니다."
- **명절**: "추석 연휴 행복하고, 안전하게 보내시길 기원합니다." / "추석 연휴 가족과 즐겁고 행복한 시간 보내셨는지요?"
- **연말**: "벌써 한 해가 저물어 가네요. 연말이라 바쁘실 텐데, 일정 잘 마무리하시고 뜻깊게 보내시기 바랍니다."
- **봄**: "봄비가 풀잎을 촉촉이 적시는 아침입니다. 따스한 차 한잔 하셨는지요?" / "미세먼지로 하늘이 뿌옇네요. 코는 답답하지만, 마음만은 상쾌한 한 주 보내세요."
- **여름**: "연일 불볕더위가 기승을 부리지만, 마음만은 시원하고 상쾌한 하루 보내세요." / "갑자기 폭우가 쏟아지네요. 빗길 안전운전하시고, 평온한 저녁 보내시기 바랍니다."
- **가을**: "아침저녁으로 서늘한 바람이 깃드는 걸 보니 가을인가 봅니다. 환절기 감기 조심하세요."
- **겨울**: "코끝이 시리게 추운 날이지만, 마음만은 화롯불 같은 하루 보내시기 바랍니다." / "어느새 12월에 접어들고 날씨가 많이 추워졌습니다."

날씨 문구는 실제 날씨와 맞아야 한다. 발송 시점의 계절·날씨를 모르면 휴일·연중 문구를 쓰거나 사용자에게 확인한다.

## 10. 출력 형식

**작성 요청 시**
```
① 그대로 보낼 제목과 본문
② 고친(정한) 이유 3줄: 유형, 핵심 구성, 뺀 내용
③ 확인 필요 사항: 빈 기한·시각, 문의처, 수신자 직급 가정 등
```
기한·수치·이름·연락처는 사용자가 준 것만 쓰고, 없으면 `[ ]`로 남겨 확인을 요청한다.

**교정 요청 시**
```
**수정의견**
1. "원문 인용" → 문제 유형(I 관점/할 일 묻힘/주제 왕복/사족/중문/중복어/부탁·강조어 남발/표기 불일치/I·B 규칙 등)
   → 수정 방향
**수정 후**
(그대로 보낼 제목과 본문)
```
마지막에 전체 공통 지적을 3줄 이내로 요약한다.
